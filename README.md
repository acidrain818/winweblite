## about
winweblite is a very basic and lightweight website builder for making static webpages on older or lower end computers. it should be compatible with windows 7 but I have not tested it. my windows 7 computer hasnt arrived yet

## how to use
winweblite is very straightforward to use if you have a basic knowlege of how to use a website builder. 
on the left is your directory. the one at the top is your main folder, below it are the pages of your website which is in the folder
on the right is your edit panel thing. this is very easy to figure out and i dont really know how to explain it so just TRUST ME okay
on the top you have file, edit and insert buttons (obviously) and under them you have buttons to add or delete a page (+page and -page). 
next to the add and delete page buttons you have buttons to insert different elements you can add to your website
the preview button previews your site in your default browser
the publish html button exports it to a folder.
